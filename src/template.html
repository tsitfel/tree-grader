채점 방식 · 실행 환경 안내
  • 코드는 브라우저 안의 C 인터프리터로 실행되며 외부로 전송되지 않습니다. 표준 라이브러리(stdio, stdlib, string, math, ctype, stdbool)의 주요 함수를 지원합니다. 파일 입출력, goto, 비트필드는 지원하지 않습니다. scanf_s, #pragma, _CRT_SECURE_NO_WARNINGS 같은 Visual Studio 관용구는 그대로 허용됩니다.
  • 출력 비교는 줄 단위로 하며, 각 줄의 앞뒤 공백과 연속 공백 개수 차이는 무시합니다. 줄 수나 줄의 내용이 다르면 틀린 것으로 판정합니다.
  • 점수는 테스트별 배점의 합(100점 만점)입니다. 정답 코드(교재 알고리즘)의 출력이 기준이며, 삭제 시 중위 후계자 사용·AVL 동점 처리 규칙 등 교재의 규칙을 따라야 같은 트리가 됩니다.
  • NULL 역참조, 해제한 메모리 재사용, 초기화되지 않은 값 읽기, 할당 범위를 벗어난 접근 같은 메모리 오류는 실제 컴파일러에서는 우연히 동작할 수 있지만 여기서는 오류로 잡아 줄 번호와 함께 알려줍니다.
  • 실행 단계 300만 회 또는 3초를 넘으면 시간 초과(무한 루프)로 처리합니다.
