# 탐색트리 실습 채점기 (Tree Grader)

알고리즘 실습 7주차 **이진탐색트리 · AVL 트리** 과제용 자동 채점 웹페이지입니다.
학생이 작성한 C 코드를 붙여 넣으면 브라우저 안에서 바로 실행해 **점수(100점 만점)** 와, 틀린 경우 **작성 방향 힌트**를 보여 줍니다.

- 서버가 필요 없습니다. `index.html` 한 파일로 동작하며, 코드는 외부로 전송되지 않습니다.
- C 코드는 페이지에 내장된 C 인터프리터(JavaScript)로 실행됩니다.
  NULL 역참조, free 후 사용, 초기화되지 않은 값 읽기, 할당 범위 초과, 무한 루프, 반환값 누락, 포인터·정수 혼동 등을 줄 번호와 함께 한국어로 알려 줍니다.

## 문제
| 문제 | 내용 | 명령 |
|---|---|---|
| 1 | 이진탐색트리 구현 (외부노드 방식) | `i k` 삽입, `d k` 삭제, `s k` 탐색, `p` 전위순회, `q` 종료 |
| 2 | AVL 트리 생성 (삽입·탐색) | `i`, `s`, `p`, `q` |
| 3 | AVL 트리 삭제 | `i`, `d`, `s`, `p`, `q` |

## 채점 방식
- 문제지 예시를 포함한 유형별 테스트(삽입·탐색·삭제 case 1/2·루트 삭제·단일/이중회전·비루트 회전·높이 갱신·동점 처리·연쇄 회전·종합) 46개.
- 출력은 줄 단위로 비교하며 줄 앞뒤 공백·연속 공백 차이는 무시합니다.
- 기준 출력은 교재 알고리즘(삭제 시 중위 후계자, AVL 삭제의 동점 처리 규칙)을 따릅니다.
- 실행 제한: 300만 단계 또는 3초, 함수 호출 깊이 1000.

## 소스 구조
```
index.html            완성 페이지 (GitHub Pages 로 바로 게시)
src/engine/cfront.js  C 전처리기·어휘분석기·구문분석기
src/engine/cruntime.js 인터프리터 런타임(메모리 검사, 표준 라이브러리)
src/engine/run.js     명령행 실행기: node run.js prog.c input.txt
src/template.html     페이지 템플릿 (문제 설명, 힌트 규칙, UI)
src/tests.json        테스트케이스 (유형·배점·힌트·입력·기대 출력)
src/gen_tests.js      정답 코드로 tests.json 을 다시 만드는 생성기
src/fuzz.js           gcc 결과와 인터프리터 결과를 비교하는 차분 테스트
src/build.js          node build.js → index.html
```
테스트케이스·배점·힌트를 바꾸려면 `src/gen_tests.js` 를 수정한 뒤 `node gen_tests.js`(정답 코드를 gcc 로 빌드한 `ref7_1`, `ref7_2`, `ref7_3` 와 추적용 `tests/ref7_*_trace` 가 필요) → `node build.js` 를 실행합니다.

정답 코드와 다른 구현 예시(.c)는 학생에게 공개되지 않도록 이 저장소에 포함하지 않았습니다.
